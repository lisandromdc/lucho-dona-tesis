# lucho-dona-tesis

Sitio web del **ANEXO I: Manual de Herramientas Sostenibles (MHDS)** de la tesis de graduación FADU|UNL:

> *Estrategias proyectuales para la eficiencia energética en viviendas unifamiliares: bases para un manual abierto de buenas prácticas. Caso: San Carlos Centro.*
>
> Dona Luciano | Ramira Camila

## Estructura

- [`mhds/`](mhds/) — página web estática (HTML/CSS/JS, sin build). El contenido del manual está en [`mhds/data.js`](mhds/data.js) y respeta de forma literal los textos del documento original.

## Desarrollo

No requiere dependencias: abrir `mhds/index.html` en el navegador, o servir la carpeta con cualquier server estático.

## Deploy

Deployado en Vercel (proyecto `mhds`, root directory `mhds/`).
